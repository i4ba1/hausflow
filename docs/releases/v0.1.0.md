# HausFlow v0.1.0 — Portfolio preview

HausFlow is an independent property-maintenance portfolio app. This first release provides a credential-free public preview and a connected demo workflow that can be enabled with development Clerk and Convex accounts.

## Included

- Responsive inbox preview with three synthetic tenant requests, search, property context, and cited suggested next steps.
- Organization-scoped demo data, maintenance cases, manager review and approval, simulated delivery, retries, reminders, and reset safety.
- Owner-only CSV import for buildings, units, and tenants with staged validation, row errors, progress, and safe repeat imports.
- Architecture, product requirements, setup instructions, screenshots, and an animated public-preview demo.

## Verification

Formatting, lint, TypeScript, and the production build pass. The local Convex harness passes 15 backend tests, and Playwright passes four desktop/mobile browser tests.

## Current limits

The screenshots and GIF show the public preview. Authenticated workflows require development Clerk and Convex configuration and have not had a hosted smoke test. Email delivery and AI responses are simulated; live provider integrations are planned.
